## 📌 프로젝트 개요
- 자유로운 중고거래를 위한 장터, "장마당"
- 거래에 래플 방식을 도입해 기존 중고 거래에 재미 요소를 추가했습니다
- 사용자 중심의 자율성을 강조하며, 누구나 쉽고 편리하게 중고 물품을 사고팔 수 있는 온라인 플랫폼입니다 🌟
